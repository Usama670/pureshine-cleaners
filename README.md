# PureShine Cleaners

A modern, responsive cleaning service website built to provide a clean and professional online experience for customers looking for reliable cleaning services.

## 🌐 Live Demo

[PureShine Cleaners](https://pureshine-cleaners.vercel.app/)

## ✨ Features

* Modern and responsive design
* Clean and professional UI
* Fully responsive across desktop, tablet, and mobile
* Service sections for different cleaning solutions
* Customer-focused layout and navigation
* Smooth animations and interactive elements
* Contact / booking-focused sections
* Fast and optimized frontend

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* CSS
* JavaScript
* Vercel

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Usama670/pureshine-cleaners.git
```

Navigate to the project:

```bash
cd pureshine-cleaners
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will then be available on the local development server.
